DAN McKENNA HOMES – DESKTOP SHORTCUTS (Windows)

1. Copy this whole folder to Dan's laptop (USB stick, email, or download the zip).
2. Double-click  "Install (double-click me).bat".
   If Windows shows "Windows protected your PC": click "More info" -> "Run anyway".
3. A "Dan McKenna Homes" folder appears on the desktop with:
     Website          – Dan's website
     Website Editor   – add homes, change photos, request changes
4. Open "Website Editor" once and sign in, so the browser remembers it.

At launch (when danmckennahomes.com points to the new site): change $WebsiteUrl
at the top of Install-Shortcuts.ps1 and run the installer again.
